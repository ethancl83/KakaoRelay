# 검증

공개 문서에는 실제 수신자, 발송 본문, 요청 식별자, 프로필 경로, 원본 로그를 포함하지 않습니다.

## 자동 검증

- 대상 창 식별, 숨김/최소화/동명 방 처리
- 기존 초안 보호, 한글·줄바꿈 비교
- 요청 중복, ID 충돌, 입력·전송 중 중단, 불확실한 결과 재시도 방지
- 발송 후 작성 세션 자동 완료, 즉시 다음 메시지 작성
- HTTP 인증, 브라우저 요청 차단, 잘못된 JSON·ID, 수신방 없음
- 12,000자 이상의 본문 전달, 본문 미저장, 서버 종료 시 토큰 파일 정리
- 진단 worker의 성공·시간 초과·취소·부분 결과 보존

현재 자동 검증 51개를 실행합니다. 발송 통합 테스트는 실제 수신방 대신 대체 전송기를 사용합니다.

## 실제 환경에서 확인한 범위

이전 버전에서 사용자가 승인한 테스트 방을 대상으로 앱 전송 엔진이 입력과 Enter 요청을 처리하고,
새 발신 말풍선이 나타나는 것을 확인했습니다. 상대방 읽음 여부는 추론하지 않습니다.

발송/이력/연결·API 탭과 로컬 health/rooms/capabilities/requests 응답을 확인했습니다.
아이콘·트레이 수명 검증 결과는 해당 버전 변경과 함께 기록합니다.

최근 대화 DB는 파일 형식 조사만 수행했으며 복호화나 최근 대화 조회가 검증되었다고 주장하지 않습니다.
