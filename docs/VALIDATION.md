# 검증

공개 문서에는 실제 수신자, 발송 본문, 요청 식별자, 프로필 경로, 원본 로그를 포함하지 않습니다.

## 자동 검증

- 대상 창 식별, 숨김/최소화/동명 방 처리
- 기존 초안 보호, 한글·줄바꿈 비교
- 요청 중복, ID 충돌, 입력·전송 중 중단, 불확실한 결과 재시도 방지
- 발송 후 작성 세션 자동 완료, 즉시 다음 메시지 작성
- HTTP 인증, 브라우저 요청 차단, 잘못된 JSON·ID, 수신방 없음
- 12,000자 이상의 본문 전달, 본문 미저장, 서버 종료 시 토큰 파일 정리
- 진단 worker의 성공·시간 초과·취소·부분 결과 보존

v0.6 Windows 자동 검증 81개와 공통 엔진의 Portable 검증 16개를 실행했습니다. 발송 통합 테스트는 실제 수신방 대신 대체 전송기를 사용합니다.

추가 검증: 프로바이더 순서·직접 선택·설정 저장, 대화 TXT/JSON 파싱, 프롬프트의 삭제 본문 제외, Unicode stdin, CLI 시간 초과·취소, AI API 인증·생성과 발송 분리, SQLCipher 인증·WAL 커밋·손상된 꼬리 처리, 자동 답장 ID 기준점·자기 메시지 제외.

## 실제 환경에서 확인한 범위

이전 버전에서 사용자가 승인한 테스트 방을 대상으로 앱 전송 엔진이 입력과 Enter 요청을 처리하고,
새 발신 말풍선이 나타나는 것을 확인했습니다. 상대방 읽음 여부는 추론하지 않습니다.

발송/이력/연결·API 탭과 로컬 health/rooms/capabilities/requests 응답을 확인했습니다.
아이콘·트레이 수명 검증 결과는 해당 버전 변경과 함께 기록합니다.

2026-09-29 C# 읽기 엔진으로 로컬 방 19개 중 메모리에 키가 확인된 5개 방, 총 107개 기록을 DB/WAL 인증 및 SQLite 무결성 확인 후 읽었습니다. Python 의존성 없이 실행했습니다. 원본은 읽기 전용이며 새 엔진은 평문 DB를 디스크에 쓰지 않습니다.

Codex CLI 실제 호출에서 한국어 응답을 받았습니다. Portable UI에서 가상 인물의 테스트 대화 파일 가져오기 → Codex 분석 → 결과 표시를 확인했습니다. Windows AI 패널은 오프스크린 WPF 렌더로 기본 레이아웃을 확인했습니다.

Grok Build 1.0.41과 Claude Code 2.1.274 설치 및 호출 옵션 파싱을 확인했습니다. 두 프로바이더의 로그인 후 모델 응답은 검증하지 않았습니다. 자동 답장은 실제 카카오톡 발송으로 시험하지 않았습니다. macOS/Linux는 공통 코드 빌드·테스트를 Windows에서 수행했으며 실제 OS 실행·서명·패키징은 미검증입니다.
