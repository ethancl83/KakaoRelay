# 아이콘

내장 imagegen으로 만든 원본 PNG를 프로젝트에 보존하고, Build-Icon.ps1로
16, 20, 24, 32, 40, 48, 64, 128, 256px PNG 프레임이 포함된 Windows ICO로 패키징했습니다.
실행 파일·창·트레이가 같은 아이콘을 사용합니다.

원본: `src/KakaoRelay.App/Assets/KakaoRelay.png`
배포 아이콘: `src/KakaoRelay.App/Assets/KakaoRelay.ico`

사용 프롬프트:

> Create one production Windows desktop app icon for KakaoRelay, a local messaging relay utility. Square centered flat pictogram, a solid teal (#087E83) rounded-square tile occupying 92% of the canvas, white simple speech bubble containing one bold teal right-pointing arrow, thick shapes readable at 16x16 pixels. One mark only, no lettering, no text, no multiple icons, no mockup, no 3D, no shadows. Transparent background outside rounded tile. Crisp uncluttered silhouette, high contrast.
